Ever since I found out about emulation years ago, I´ve been using it as my go to for my retro gaming needs. All I needed was a laptop and an emulator. But over the years I can´t quite shake the feeling that somethings is missing and thus began by search for the perfect setup.

This was inspired by the ammount of updates and inovations in the emulation community, you´ve got now shaders that make games look like how they were originally supposed to, and got frontends now that turn your pc into a home console.

After spending hours perusing video tutorials, wikis and forums here´s how I made my own gaming setup.

## The Hardware

![A black latop on a desk](/images/2026/laptop.jpg)

The first set for a retro or any harder emulation setup is of course the hardware. It can make it or break it, the better specs the more systems you can emulated without issues, if you take in upcaling graphics and adding upgraded textures backs, it can affect the performance of the game.

At first I was really tempted to get those shiny mini pc´s everyone´s talking about, they´re great if you want to do have an entertaiment setup for your living room..

But I´m kinda of a cheapskate, and sometimes using what you already have can be just as valid, so I´m using my laptop, yes same one I´m writing this post on.

It´s An Asus Vivobook, its got 16 gb of ram, with an AMD processor (Ryzen 7 4700U) and Graphics Cards (Radeon with 4gb vram), and while I´ve had it for what 4 or 5 years, it still runs like a charm. And thanks to ESU deciding to expand another year for EU users, I´m still using Windows 10.

This is enough for pretty much every retro system, however I haven´t tested playstation 3 emulation, but everything up to switch works. This is good news out there for those who you have bought a pc in the last few years or recently. And because of work done for optimization, and of course there are plenty of guides out there that teach you how to tweak emulators for better performance, so it´s a matter of searching around.

It might have to coexist with other stuff on my computer like my music files and work/project stuff, so I have to careful with the size and numbers of games, but I don´t mind a curated selection.

![A black Krom Key Game Controller](/images/2026/kromkey.jpg)

As for the controller I´m using a wired Krom Key Controller, it´s not the most premium but I haven´t had any complaints, I might eventually switch to wireless one in the future.

## Frontend or Standalone Emulators?

Standalone emulators have been my preferred method of retrogaming, mostly because I did try retroarch, but boy is it hard to use, so I would install a bunch of them put them in a folders alonside the roms and that was it.

Plus they had better performance wise and were easier to tweaks its configuration. Eventually I came across a game manager called [Playnite](https://playnite.link/), which at first I would use it to reorganize my pc game collection across several platforms, and then I found you can also add emuladed games there.

It got me thinking, perhaps using a frontend would be a better way to organize my retro games than instead having to go through my folder and remember which game is playable by which system.

That being said, I found out I didn´t like having to set up manually each game and emulator on playnite, unlike with pc games that with the addons would connect to your game account and have them already showed up on the list complete with boxart. So the search for a front end was on.

But what to use? Batocera? Maybe, but its a linux operating system, I guess I can use an external hardrive or a usb drive with a big size. But i have to remember to turn on the computer to that system insted of windows and it´s probbly best for mini-pcs.

There´some other Launch box seemsdecent enough, but if you want extra feature you can pay for a license that wil give you updates up to a year. Eventually I settle for [retrobat](https://www.retrobat.org/en/). Its opensource, freely available and powered by Emulation Station.

## Setting RetroBat

![retrobat menu](/images/2026/retrobatmenu.jpg)

It was [much easier](https://youtu.be/lwNE76UceEk) than I though, according to [the guide](https://wiki.retrobat.org/get-started/installation-and-first-startup) all I had to do was install it, then I would go to the folder where I installed it, put the roms on the roms folder and put bios files on the bios folder. For ease of use I found a bios pack [on github](https://github.com/Abdess/retrobios). As for the roms, I collected them over the years.

But my go to source has either been vimm´s lair and the internet archive, on the archive I even found a currated back for games compatible for retroachivements.

It´s not enough, which is why I connect it to my retroachivements account (if you never heard of it, it unlocks achivemnts for retro titles) and of  course my [screenscraper](https://www.screenscraper.fr/) account, since I will be using it to scrape game art. Then I use the scrape option and let it do its thing.

I also downloaded a shader pack, and I know I can change theme but I haven´t settled on one, another time then.

Then it´s game time right? Not quite, I decided to play with the game setting for a bit, you can modernize them for a bit, but my ass want them to feel more oldschool so i tried the 4:3, with added bezels and a shader. Excpet well when I´m running CRT Royale or Lottes CRT, it starts lagging, I´ve been trying to change the video configuration for playstation 2 (using pscx2 emulator).

So I either have to forgo shaders or use something else. For playstation 1, CRT New Pixie work fine, also maybe zfast since its not as heavy. But I would love to know if there is a decent guide that helps with the best settings to tweak.

## Playing on the TV

![Two men playing a game in front of a tv with game controllers on their hands](/images/2026/twoguysplaying.jpg)

Now that is all setup, the next step, now playing on a desktop is fine, but sometimes I get tired of sitting on a desk all day and want something a bit more comfy. But I only got a laptop (which is why I thoguht a mini pc would come in handy). I could connect it to the tv with and hdmi cable.

But remeber I don´t have a wireless controller yet. Then I remember, hey my phone and internet provider came with the installation of an andorid tv box. To this ends I installed two apps, steam link (for my steam games) and [moonlight game streaming](https://moonlight-stream.org/) for the rest.

Setup was easy, I installed [sunshine](https://app.lizardbyte.dev/Sunshine/) which makes my laptop into the host, created username and password and it gives me a pin. I only have to do this once. Steam link is much conveinient thought, I only have to turn on steam, which link will detect.

This way I can set up my latop a bit closer so I can use the controller.

## It´s Gaming Time

Now that I am happy enough I now have my perfect setup, using only a laptop and not having through any extra expenses. Of course it could change in the future, honestly those retro handhelds like the ayn thor and retroid pocket 6, which are not only very protable but you can connect them to the tv. Maybe once I saved up to get one. 

This is probably how I gonna get family into retro gaming aren´t I? Well that´s what the extra controller is for.

To conclude, if there are any fellow retro gamers out there I woud like to know how you made you´re set up and if they´re are any hints to as how can I improve it.

As for my portable setup that is for another post.
